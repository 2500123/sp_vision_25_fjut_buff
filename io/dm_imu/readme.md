达妙 IMU（DM IMU）的串口驱动模块，独立于 CAN 和 C板虚拟串口方案，为视觉端直接从 IMU 取姿态提供通道。

关键功能（在 dm_imu.cpp）：

串口初始化：固定打开 /dev/ttyACM0，波特率 921600（可根据实际设备调整）。
后台读取线程：持续按达妙 IMU的自定义二进制协议读帧（帧头包含 0x55 0xAA 0x01 0x01 等），逐段校验 CRC16。
数据解析：提取加速度、角速度、欧拉角（roll/pitch/yaw，单位度），将其按 Z-Y-X 顺序转换为四元数并归一化，打上时间戳。
时间插值：提供 imu_at(timestamp)，在内部队列中用 SLERP（球面插值）按时间插值得到指定时刻的姿态四元数。
典型使用场景：

当没有使用 C 板（MicroUSB 虚拟串口）或 CAN 时，直接接入达妙 IMU 获取姿态。
在视觉-IMU同步与位姿解算（如 Solver::set_R_gimbal2world）里，作为四元数 q 的数据源之一。
注意事项与建议：

目前串口设备路径写死为 /dev/ttyACM0，建议用 udev 规则固定为 /dev/dm_imu 并把端口做成可配置项（YAML），以免重插变化。
确保用户在 dialout 组，串口权限正确。
若数据频繁校验失败，检查线缆、波特率、协议帧格式是否匹配达妙固件版本。
